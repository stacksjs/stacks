# Design

Premium UI work, aesthetic presets, image-first pipelines and diagrams.

Visual quality has its own set. [Design taste](/skills/design/design-taste) is
the flagship and carries the shared rules; the aesthetic presets and the
image-first pipelines refine it and defer to it.

12 skills.

| Skill | What it is for |
|---|---|
| [Brand kit](/skills/design/brandkit) | Explores a brand identity as reference images before any code exists: logo directions, palettes, typography specimens, identity boards and application mockups. |
| [Design: brutalist](/skills/design/design-brutalist) | An aesthetic preset for industrial and brutalist work: Swiss typography, sharp high contrast, rigid modular grids, monospace telemetry and experimental analog-degradation effects. |
| [Design: minimalist](/skills/design/design-minimalist) | An aesthetic preset for editorial and minimalist surfaces, the Notion and Linear register: restrained warm monochrome, typographic contrast, flat bento grids, muted accents, no gradients and no heavy shadows. |
| [Design: full output](/skills/design/design-output) | An enforcement layer for when an agent keeps truncating. It bans placeholder comments and elisions so you get whole, runnable stx files rather than skeletons with "rest of the component here" in them. |
| [Design: soft](/skills/design/design-soft) | An aesthetic preset for work that should feel expensive: generous whitespace, premium type, soft diffused shadows and spring-like motion. |
| [Design taste](/skills/design/design-taste) | The flagship design skill and the one to start from. It reads the brief, infers a direction, and ships stx and Crosswind interfaces that do not look templated, governed by three dials (variance, motion, density), an explicit list of AI tells to avoid, and a pre-flight check that has to be honestly tickable before the work is done. |
| [Design taste (Codex)](/skills/design/design-taste-codex) | The stricter variant of [Design taste](/skills/design/design-taste), tuned for award-level work and for the OpenAI Codex CLI as well as Claude Code. |
| [Image to code](/skills/design/image-to-code) | An image-first pipeline for a visually important page: generate design reference images, analyse them deeply, then implement to match in stx and Crosswind. |
| [Image generation: mobile](/skills/design/imagegen-mobile) | Generates premium mobile app screens and flows as reference images, shown inside clean iOS, Android or cross-platform phone mockups. |
| [Image generation: web](/skills/design/imagegen-web) | Generates premium website reference images and nothing else, one horizontal frame per section. |
| [Redesign](/skills/design/redesign) | The audit-first companion to [Design taste](/skills/design/design-taste). |
| [Technical diagrams](/skills/design/technical-diagrams) | Architecture, workflow, sequence, data flow and lifecycle diagrams. |

Every page here describes one `SKILL.md` under
[`storage/framework/defaults/ai/skills`](https://github.com/stacksjs/stacks/tree/main/storage/framework/defaults/ai/skills).
See [Using skills](/skills/using) to wire them into your agent.
