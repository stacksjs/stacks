# Design: soft

`stacks-design-soft` · Design · model-invoked

An aesthetic preset for work that should feel expensive: generous whitespace,
premium type, soft diffused shadows and spring-like motion. Composes with
[Design taste](/skills/design/design-taste), which carries the shared rules.

## When to reach for it

- Designing a landing page
- Hero
- Marketing section
- Pricing
- Portfolio that needs generous whitespace
- Premium fonts
- Soft diffused shadows
- Spring-like motion
