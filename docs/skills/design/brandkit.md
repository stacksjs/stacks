# Brand kit

`stacks-brandkit` · Design · model-invoked

Explores a brand identity as reference images before any code exists: logo
directions, palettes, typography specimens, identity boards and application
mockups. Images only, with intentional logo concepting and disciplined palettes a
coding step can build against.

## When to reach for it

- Logo directions
- Palettes
- Typography specimens
- Identity boards
- application/mockup decks
