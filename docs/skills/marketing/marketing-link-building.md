# Link Building

Use `stacks-marketing-link-building` when planning backlinks or third-party mentions - prospecting, relevance, qualification and outreach drafts. Covers marketing authority and AI citations.

This skill is **model-invoked**. Your agent can select it for matching tasks, and you can call it directly.

Source: [`stacks-marketing-link-building/SKILL.md`](https://github.com/stacksjs/stacks/blob/main/storage/framework/defaults/ai/skills/stacks-marketing-link-building/SKILL.md).

It ships with its supporting files in `@stacksjs/defaults`. Run
`buddy setup:ai` to refresh agent setup. Override it with
`app/Skills/stacks-marketing-link-building/SKILL.md`. See [Using skills](/skills/using).
