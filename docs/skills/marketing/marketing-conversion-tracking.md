# Conversion Tracking

Use `stacks-marketing-conversion-tracking` when setting up or auditing conversion tracking - lead signals, purchase events, consent, platform delivery and verification. Covers marketing measurement and Stacks integration.

This skill is **model-invoked**. Your agent can select it for matching tasks, and you can call it directly.

Source: [`stacks-marketing-conversion-tracking/SKILL.md`](https://github.com/stacksjs/stacks/blob/main/storage/framework/defaults/ai/skills/stacks-marketing-conversion-tracking/SKILL.md).

It ships with its supporting files in `@stacksjs/defaults`. Run
`buddy setup:ai` to refresh agent setup. Override it with
`app/Skills/stacks-marketing-conversion-tracking/SKILL.md`. See [Using skills](/skills/using).
