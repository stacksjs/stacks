## Distribution and maintenance

`@stacksjs/defaults` includes the entire AI directory. Managed defaults sync
delivers the skills, references, assets, and license notices to new apps and
upgrades. `buddy setup:ai` exposes the merged framework and project skills.

To refresh, inspect the upstream catalog at a concrete revision, compare each
source with its mapped Stacks workflow, and update the playbook or native
substitute. Preserve local Stacks API guidance and project authorization rules.
Update the mapping and hashes with the reviewed revision. Run the provenance,
docs, discovery, and installation checks before shipping. Do not replace
framework defaults with an unreviewed remote install.
