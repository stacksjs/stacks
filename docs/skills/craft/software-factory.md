# Software Factory

Use `stacks-software-factory` when designing recurring agent work - ticket sources, orchestration, runners, Git integration, human review and observability. Covers engineering workflow architecture.

This skill is **model-invoked**. Your agent can select it for matching tasks, and you can call it directly.

Source: [`stacks-software-factory/SKILL.md`](https://github.com/stacksjs/stacks/blob/main/storage/framework/defaults/ai/skills/stacks-software-factory/SKILL.md).

It ships with its supporting files in `@stacksjs/defaults`. Run
`buddy setup:ai` to refresh agent setup. Override it with
`app/Skills/stacks-software-factory/SKILL.md`. See [Using skills](/skills/using).
