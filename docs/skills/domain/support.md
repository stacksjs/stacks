# Support

`stacks-support` · Native Stacks · model-invoked

Use when connecting an application to HQ.support, issuing customer sessions, creating support conversations, forwarding customer events, or controlling its stx messenger. Covers @stacksjs/support and services.supporthq.

## Inside the skill

- Server
- Browser
- Verification

## Using it

This skill is **model-invoked**. Your agent can select it for matching tasks.

```text
/stacks-support
```

Source: [`stacks-support/SKILL.md`](https://github.com/stacksjs/stacks/blob/main/storage/framework/defaults/ai/skills/stacks-support/SKILL.md).

It ships in `@stacksjs/defaults`. Run `buddy setup:ai` to refresh the agent setup.
